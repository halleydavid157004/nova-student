NOVA STUDENT RADAR - INICIO EN WINDOWS

1. Descomprime completamente el proyecto.
2. Instala Node.js 24 LTS desde https://nodejs.org/ si no lo tienes.
   El codigo conserva compatibilidad con Node 20, que ya esta fuera de soporte.
3. Abre ABRIR_NOVA_STUDENT.cmd: es el unico lanzador.
4. El navegador abre http://127.0.0.1:4310 (o el PORT configurado).

El lanzador crea .env desde .env.example y detecta una instancia sana.
El servidor usa modulos incluidos en Node; arrancar no necesita npm install.
Si falla, abre Nova Student Radar Server para leer el error o ejecuta:
  ABRIR_NOVA_STUDENT.cmd --diagnostico
No se crea un archivo server.log automaticamente.

CONFIGURACION (secretos solo en .env o variables del servidor):
- Nova AI: GROQ_API_KEY. El modelo y alternativas se configuran en .env.
- Radar: BRAVE_SEARCH_API_KEY; maximo 600 solicitudes/mes para esta app.
- Persistencia: SUPABASE_URL + SUPABASE_SECRET_KEY solo en el servidor.
  La arquitectura actual requiere UN SOLO escritor; no lances otro scanner.
- Correo en Render Free: Resend HTTPS con dominio ya verificado.
  SMTP de Gmail solo es alternativa local; Render Free bloquea esos puertos.
- ADMIN_TOKEN debe ser secreto y distinto del valor de ejemplo.

TESTS:
  npm ci
  npm test
La suite usa proveedores simulados. Guardar una alerta no prueba entrega.
La extension actual usa localhost: revisa README antes de instalarla.

Nunca subas .env, correos de suscriptores ni copias privadas a GitHub.
Consulta README.md, docs/AUDIT.md y docs/FREE_TIER_LIMITS.md para limites,
riesgos pendientes y la evolucion por fases. El propietario despliega Render.
