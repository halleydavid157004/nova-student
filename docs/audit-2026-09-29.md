## Operación gratuita

Render permanece en Free. Supabase es opcional y debe configurarse con la tabla y las variables del README; antes de esa configuración, Render conserva almacenamiento temporal. Groq requiere una clave válida y tiene cuotas del proveedor. Los límites de API del servidor evitan colas ilimitadas. El correo necesita un proveedor y remitente admitidos; guardarlo no prueba entrega.

La instantánea de Supabase admite un solo escritor. No se debe ejecutar otro servidor o escáner contra la misma fila. La conexión HTTPS desde Render requiere sus variables configuradas y el despliegue manual del propietario.
