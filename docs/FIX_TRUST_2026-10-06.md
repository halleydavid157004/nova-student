# Confianza de fuentes — 6/oct/2026

La propiedad no se infiere por palabras en el hostname. Solo URLs educativas explícitas de la lista curada y semillas oficiales confieren confianza automática. El enlace canónico completo debe coincidir: un blog en el dominio de la marca no basta. Parámetros de seguimiento se deduplican; variantes de plan se conservan.

Pistas StudentOffers nuevas desconocidas quedan no oficiales. Cada ciclo corrige promociones antiguas del mismo origen que no coincidan con el registro, antes del flush y autoaprobación. No cambia aprobaciones humanas ni retira ofertas reviewed por un fallo. Historial y ofertas permanecen en la base para revisión. La pérdida de confianza de una fuente impide nuevas aprobaciones automáticas.

No hay DDL ni dependencias nuevas. Mantener la aprobación automática detenida durante la reparación operativa; después comprobar lista de fuentes y cola. No reactivarla sin revisión de las promociones históricas y administrador disponible. Rollback de código no debe reintroducir la heurística insegura: mantener NOVA_AUTO_APPROVE=false o el interruptor SQL apagado.

Pruebas: URLs conocidas, páginas desconocidas del mismo proveedor, subdominios impostores, URL con credenciales, idempotencia y reparación de fuentes antiguas. Ninguna prueba consulta un dominio impostor.
